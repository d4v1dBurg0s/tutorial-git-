# Tutorial de Git - Actividad 2

Este repositorio contiene el tutorial de Git desarrollado para la Actividad 2 de la Unidad 2.

## Proceso realizado:
1. Instalé Git en mi computadora.
2. Creé un repositorio en GitHub y lo cloné localmente usando `git clone`.
3. Creé los capítulos del tutorial en Microsoft Word y los exporté a PDF.
4. Utilicé los comandos `git add`, `git commit` y `git push` para subir los archivos.

## Dificultades encontradas:
- Al principio intenté escribir `git clone` en la página web de GitHub, lo cual no funcionó.
- Tuve un error de "Author identity unknown" porque no había configurado mi usuario y correo en Git. Lo solucioné con `git config --global`.

## Comandos utilizados:
- `git clone <url>`
- `git add .`
- `git commit -m "mensaje"`
- `git push origin main`
